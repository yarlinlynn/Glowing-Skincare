# ✨ Glowing — Skincare E-Commerce Website
A responsive skincare e-commerce website recreated from the [Glowing Skincare E-Commerce Website](https://glowing-skincare-ecommerce-website.netlify.app/).

This project is built from scratch using **HTML, Tailwind CSS and JavaScript** without using a frontend framework such as React or Vue.
The goal of this project is to recreate the original design while practicing modern frontend development techniques including reusable JavaScript components, responsive layouts, Tailwind CSS, DOM manipulation, animations, and interactive navigation.

## 📖 About The Project

Glowing is a modern skincare e-commerce storefront designed around a clean, minimal and responsive user interface.
This recreation focuses on reproducing the visual design and interactive behaviour of the original website while implementing the interface using a lightweight vanilla JavaScript architecture.
Instead of using React, Vue, or another component framework, the project uses JavaScript functions that return HTML strings.

- JavaScript (ES Modules)
